# 🎵 网页音乐播放器

> Web 前端编程技术实验 · 纯原生 HTML + CSS + JavaScript

一个功能完整的网页音乐播放器，支持播放列表管理、循环模式切换、音量控制与歌词/唱片视觉展示。

## 🔗 在线预览

**https://qty124.github.io/music-player/**

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 播放控制 | 上一首 / 播放暂停 / 下一首 |
| 播放列表 | 曲库列表，点击切换，���前歌曲高亮 |
| 循环模式 | 顺序播放 / 单曲循环 / 随机播放 三态切换 |
| 音量控制 | 静音切换 + 滑块调节 |
| 进度条 | 播放进度显示与拖拽跳转 |
| 视觉 | 旋转唱片、背景切换、歌词展示 |

## 📁 结构

```
music-player/
├── index.html      # 单页入口
├── main.js         # 播放器逻辑（Audio API、列表、循环模式）
├── img/            # 图标与背景资源
└── mp3/            # 音频文件（3 首）
```

## 🛠 技术栈

- **HTML5 Audio API** — 音频播放与进度控制
- **CSS3** — 动画（唱片旋转）、Flexbox 布局、响应式
- **Vanilla JavaScript** — 无框架、无构建工具

## 🚀 本地运行

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> ⚠️ 需通过 HTTP 访问而非直接 `file://` 打开，否则浏览器可能阻止音频加载。
